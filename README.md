# Basic Button Project

This repository contains a simple HTML page with a styled button, navigation bar, and supporting CSS and JavaScript files.

## Project Structure

- `index.html` – Main HTML file (Czech language)
- `style.css` – Styles for layout, navigation, button, etc.
- `script.js` – JavaScript handling button click alert
- `.gitignore` – Files and directories ignored by Git
- `README.md` – Project documentation (this file)

## Setup & Usage

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. Open `index.html` in a web browser to view the page.
